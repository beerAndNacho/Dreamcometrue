# Macro Invest 사용자 매뉴얼

버전 5.0.2 · 2026-11-28 · 개인용 거시경제·투자 분석 프로그램

이 설명서는 설치부터 매일의 투자 리서치까지 실제 프로그램 사용 절차를 안내합니다. 103개 수집 대상 지표와 5개 파생 참고치, 국내 증시·기업가치 분석, AI 보고서 및 포트폴리오 도구를 포함합니다. 등록 대상 개수와 실제 수집 성공 개수는 다릅니다. 거래 주문은 실행하지 않으며, 모든 위험 점수·적정가·투자 시나리오는 검증된 수익률 예측이나 매매 권고가 아닙니다.

## 01. 처음 실행하기

### Windows / Mac / Linux

- Python 3.11 이상을 설치하고 프로젝트를 내려받습니다.
- Windows: `start-demo.bat`로 가상 데이터 체험, `start-live.bat`로 실데이터 모드 실행.
- Mac/Linux: `sh start-demo.sh` 또는 `sh start-live.sh`.
- 브라우저에서 `http://127.0.0.1:8000`을 엽니다. 실행 중인 터미널을 종료하면 앱과 자동 수집도 중단됩니다.
- 관리자 메뉴의 로그인 사용자명은 `admin`입니다. 최초 생성 비밀번호는 `data/settings/live/admin-password.txt` (데모는 `data/settings/demo/admin-password.txt`)에서 확인합니다. 환경변수 ADMIN_PASSWORD를 직접 설정했다면 그 값이 우선합니다.

### Docker + PostgreSQL

Docker Compose v2 설치 후 프로젝트 폴더에서 .env.example을 .env로 복사하고 DEMO_MODE=0, 충분히 긴 ADMIN_PASSWORD, POSTGRES_PASSWORD를 설정합니다. 기존 .env와 데이터를 덮어쓰지 마세요.

```bash
docker compose up --build -d
docker compose logs -f app
```

접속 주소는 동일합니다. 자동 생성된 비밀번호는 `docker compose exec app cat /app/data/settings/live/admin-password.txt`로 확인할 수 있습니다. 서버 중지에는 `docker compose down`을 사용하고, 데이터와 암호화 키를 삭제하는 down -v는 사용하지 마세요.

### 데모와 실데이터 차이

- 데모는 합성 데이터이므로 화면 체험과 계산 연습에만 사용합니다. 실제 API 수집, 연결 검사, 유료 AI 호출과 일부 자료 등록은 차단됩니다.
- 데모 DB와 설정은 실데이터 모드와 분리됩니다. 데모에 저장한 API 키가 실데이터 모드로 자동 이전되지 않습니다.
- 실데이터 처음 실행 시에는 자료가 비어 있습니다. 다음 설정 절차부터 진행하세요.

## 02. 관리자 설정 및 API 발급

접속 메뉴: 관리자 설정 (/admin). 키는 서버에 암호화 저장되고 화면에 다시 노출되지 않습니다. 모든 제공처를 반드시 등록할 필요는 없습니다.

### 제공처별 용도와 발급

- [FRED](https://fred.stlouisfed.org/docs/api/api_key.html): 미국 및 국제 거시경제·금융·산업 자료. API 키 발급 후 FRED 입력란에 등록.
- [한국은행 ECOS](https://ecos.bok.or.kr/api/): 국내 기준금리, 국고채, 환율, 증시, CPI. 실제 발급 키 필요 (sample 키는 전체 수집에 사용하지 않음).
- [OECD Data Explorer](https://data-explorer.oecd.org/): 주요국 경기선행지수. 별도 API 키 없이 조회.
- [KOSIS](https://kosis.kr/openapi/): 국내 선행·동행 순환변동치. OpenAPI 활용 신청 및 인증키 발급.
- [관세청 품목별 수출입실적](https://www.data.go.kr/data/15101609/openapi.do): 선택 사항. 활용 신청 후 서비스 키 등록. 집적회로 HS 8542와 메모리 집적회로 HS 854232의 완료 월 수출액을 조회.
- [KIS Developers](https://apiportal.koreainvestment.com/): 선택 사항. 실전용 App Key 및 App Secret을 국내 증시·기업 실적 API에 함께 등록. 읽기 전용이며 주문이나 계좌조회에는 사용하지 않음.
- [OpenDART](https://opendart.fss.or.kr/): 선택 사항. 기업 실적, 재무, 배당 자료 조회.
- OpenAI / Gemini / Claude: 선택 사항. 자동 AI 해석을 이용할 때만 제공처 키와 사용 가능한 모델 ID 등록. 일반 AI 채팅에 프롬프트를 복사하는 기능에는 필요하지 않음.

### 처음 설정하는 순서

1. FRED, ECOS, KOSIS 키를 입력하고 설정 저장을 누릅니다. 선택 API는 필요할 때 별도로 등록합니다.
2. KOSIS는 기본 순환변동치 설정 적용 버튼으로 기본 표를 채울 수 있습니다. 기존 사용자 지정 표가 있으면 무조건 변경하지 마세요.
3. 제공처별 연결 검사를 눌러 저장된 키의 표본 응답과 최근 관측값을 확인합니다. 검사에 성공해도 전체 지표 수집 성공이 보장되지는 않습니다.
4. 조회 시작일을 설정하고 지금 전체 수집을 실행합니다. 하단 상태표를 확인합니다.
5. 정상 수집을 확인한 후 자동 수집과 저장 보고서를 활성화합니다.

공란으로 저장하면 기존 키를 유지합니다. 저장 키 제거를 체크하면 환경변수로 지정한 해당 키도 무시합니다. API 키·DB 비밀번호·settings.key는 GitHub나 AI 채팅에 올리지 마세요.

KOSIS 기본 표는 orgId=101, tblId=DT_1C8015, itmId=T1, 선행 objL1=A03, 동행 objL1=B03입니다. 직접 설정 시 전국·월간·순환변동치 단일 항목의 URL 또는 쿼리를 입력합니다. 출처 변경 시 기존 이력과 수정 기록을 삭제하는 확인이 나타날 수 있습니다. CSV/DB를 백업하고 원자료를 대조한 뒤 실행하세요.

## 03. 수집 일정과 데이터 품질 확인

관리자 설정의 수집 일정 및 실행에서 자동 수집을 매일 자동 수집으로 설정하고 한국 시간 기준 시각을 선택한 뒤 일정 저장을 누릅니다. 예약 수집은 서버가 실행 중일 때 설정 시각 이후 하루 한 번 시도합니다. 처음부터 자동 수집이 켜져 있지는 않습니다.

- 지금 전체 수집: 모든 등록 지표 수집을 수동 실행합니다. 초기 이력이 많으면 시간이 걸릴 수 있습니다. 작업 중에는 중복 수집·설정 저장이 차단됩니다.
- 예약 수집: 일간 지표는 최근 이력과 겹치는 기간을 갱신하고, 일요일에는 전체 이력 수집을 시도합니다. KIS 키가 있으면 시장 수급 및 관심종목 시세·수급도 갱신합니다. 선택적으로 BLS 일정도 갱신합니다.
- 정상: 제공처 응답과 저장이 성공한 상태입니다. 관측일이 오래된 경우 화면에서 별도로 오래됨으로 표시합니다.
- 설정 필요: 필요한 키/통계표가 없습니다. 관세청처럼 선택 사항은 미등록이어도 나머지 수집을 계속합니다.
- 실패: 제공처 오류, 인증, 응답 형식, 기간 또는 데이터 검증 오류입니다. 이전 관측값은 보존되지만 신호 판단에서 제외될 수 있습니다.
- 미수집: 아직 정상 관측값이 없습니다. 0으로 해석하지 않습니다.
- 일부 성공: 일부 지표만 갱신되었습니다. 실패한 항목을 상태표에서 확인하세요.

신선도는 관측일 기준으로 일간 7일, 주간 21일, 월간 75일, 분기 190일 이내이며 수집 상태도 정상이어야 합니다. 이는 단순한 허용 지연 규칙이지 정확한 발표 일정 보장이 아닙니다. 매일 데이터를 수집해도 GDP·CPI·고용처럼 월간 또는 분기 자료는 새 발표가 없으면 변하지 않습니다. 최근 성공 시간과 실제 관측일을 함께 확인하세요.

## 04. 매일 사용하는 추천 순서

### 5.0 투자 터미널 이용 방법

- PC는 공통 사이드바, 모바일은 홈·시장·AI 보고서·자산·전체 하단 메뉴를 이용합니다. 전체 메뉴는 Escape로 닫을 수 있습니다. 테마 전환 및 대시보드 지표 선택은 현재 브라우저에 저장됩니다.
- 대시보드 상단은 미국 위험 점수·경기 국면·순유동성·SOX 1개월 가격 변화입니다. SOX 가격 변화를 실제 반도체 업황 판정으로 해석하지 않습니다.
- 대시보드 표시 지표 설정에서 기본 지표를 최대 12개 선택할 수 있고 즐겨찾기를 포함해 최대 16개 표시합니다. 경제지표는 분류·검색·정렬·즐겨찾기·신선도 필터를 제공합니다.
- 상세 그래프, 경기선행지수, 국내 수급/종가, 기업 실적/배당/가치평가, 시장 압력 차트는 화면 폭에 맞춰 그립니다. 지표를 선택하면 상세 차트가 설명보다 먼저 표시됩니다. SOX 요약 카드에서 상세 차트로 바로 이동할 수 있습니다. Y축은 읽기 쉬운 간격으로 표시하며 큰 숫자의 만·억·조는 축의 단위에 곱하는 축약 표기입니다. 날짜별 실제 관측값은 차트 아래에서 원래 단위로 확인합니다. 관측일 슬라이더·마우스·탭으로 해당 관측값을 확인합니다. 상세 그래프에는 확대 버튼도 있습니다.
- 날짜축은 실제 관측일 간격입니다. 명시적으로 누락된 값 및 지표 주기별 긴 관측 간격은 선으로 연결하지 않습니다. 국내 누적 수급은 중간 값 누락이나 10일 초과 관측 간격 이후 전체 기간 누적값을 표시하지 않습니다. 거래일 달력의 완전성 검증은 별도입니다.
- AI 투자 분석센터는 일간·주간 보고서, 경제 캘린더, 저장 이력으로 분리됩니다. 프롬프트 복사는 보고서 상단, 원자료는 펼쳐보기로 이용합니다. 새 자료 조회 실패 시 이전 보고서의 복사·저장을 보류하고 재조회하도록 안내합니다.
- 관리자 수집 상태 검색과 실패·설정 필요 등의 필터를 이용해 확인할 지표를 좁힙니다.



1. 대시보드의 신선한 지표 수, 마지막 수집 시간, 오류 개수를 확인합니다.
2. 아침 브리핑과 이전 날짜 대비 변경사항을 확인합니다. 저장 스냅샷이 없으면 과거 비교는 보류됩니다.
3. 경기순환 지도와 미국 시장 위험도, 모델 자산배분, 거시·산업·기업가치 진단을 봅니다.
4. 국내 증시 수급과 관심종목의 누적 순매수, 종가 변화를 비교합니다.
5. 투자 분석센터에서 일간 전체 시장 보고서를 열어 AI API 없이 분석하거나 자동 저장된 AI 해석을 읽습니다.
6. 경제지표 발표 캘린더에서 다음 주요 일정을 확인합니다. 실제 매매 전 공식 발표와 최신 시세를 별도로 확인합니다.

주간에는 1·3·6·12개월 변화, 장기 백분위, 주간 저장 보고서, 포트폴리오 목표 비중 차이도 확인하는 것이 좋습니다.

### 103개 수집 대상 지표 활용

- 미국 경기·고용: GDP, 산업생산, 소비, 실질소득, 실업률, 비농업 고용, JOLTS, Sahm, 주택착공, 자본재 주문 등. 성장과 고용이 함께 둔화하는지 확인.
- 물가·금리: CPI/PCE/근원, 생산자물가, 명목·실질금리, 장단기 금리차, 기대인플레이션. 금리 부담과 실물 둔화를 함께 확인.
- 유동성·신용: M2, 연준 자산, TGA, RRP, 준비금, SOFR/IORB, VIX, 하이일드 및 투자등급 스프레드, 금융여건, 은행대출·연체율.
- 한국·글로벌: 국내 CPI/GDP/실업률/생산/수출입, 코스피·코스닥, 원달러 및 주요 환율, 미국·한국·영국·일본·중국·독일·인도·G7 CLI, 한국 선행·동행 순환변동치.
- 기술·산업·기업이익: 나스닥100, SOX, 미국 반도체·전자부품 생산 및 물가, 기타 전자부품 주문·재고·출하, 한국 집적회로 수출(선택), 기업이익, 비금융기업 주식 부채.
- 원자재: WTI·브렌트유, 천연가스, 구리. 공급 충격과 수요 변화를 구분.

### 상세 화면과 내보내기

- 전체 분류, 지표명 검색, 즐겨찾기만, 신선한 자료만 필터를 활용합니다. 별표를 누르면 해당 브라우저에 즐겨찾기가 저장됩니다.
- 차트·설명을 눌러 관측 이력, 원자료 출처, 지표의 의미와 상승·하락 시 주의점을 확인합니다.
- 기간별 비교: 직전 관측값과 1·3·6·12개월 전 값을 비교합니다. 분기 지표에는 1개월 비교를 하지 않습니다.
- 5년 평균과 역사적 백분위는 충분하고 연속적인 최신 개정 이력이 있을 때만 계산합니다. 백분위 90%는 과거 관측값 대비 상대적으로 높은 위치이지 하락확률 90%가 아닙니다.
- 변화폭은 표시 단위의 차이입니다. 예를 들어 물가상승률 3%에서 4%로 변하면 1%p 상승입니다. 주가지수의 상대 변화율은 가격 수익률이며 배당 재투자 수익률이 아닙니다.
- CSV 다운로드에는 해당 지표의 관측일, 값, 단위 등이 포함됩니다. 원자료 수정 기록은 수집 이후 프로그램이 확인한 값 변경 시각이며 공식 발표 시각과 다릅니다.
- 아침 브리핑 TXT는 현재 규칙 기반 요약입니다. 투자 분석센터의 저장된 AI 보고서 및 프롬프트와 구분하세요.

## 06. 경기순환과 위험도·파생 분석

### 경기순환 지도

CLI 또는 순환변동치의 기준 100과 3개월 변화 방향을 이용합니다. 100 미만 상승=회복, 100 이상 상승=확장, 100 이상 하락=둔화, 100 미만 하락=하강. 변화폭 절댓값 0.01 미만은 보합이며 미국 CLI가 보합이거나 필수 자료가 부족하면 배분 판단이 보류됩니다.

이 분류는 프로그램의 단순 규칙입니다. 공식 경기침체 판정이나 GDP 전망이 아닙니다. 대시보드 경기순환 궤적은 미국·한국·영국 중심으로 표시되며 추가 국가의 현재 국면은 지표 카드에서 확인할 수 있습니다.

### 기존 미국 시장 위험 점수 (0~100)

- VIX: 20 이상 15점, 30 이상 30점.
- 하이일드 OAS: 4%p 이상 15점, 6%p 이상 30점.
- S&P 500이 200거래일 평균 미만: 20점.
- 미국 OECD CLI 둔화: 10점, 하강: 20점.
- 40점 미만 낮음, 40~69점 주의, 70점 이상 높음. 위험 점수는 실제 하락 확률이 아닙니다.

기본 주식/채권/현금 비중은 회복 70/20/10%, 확장 65/25/10%, 둔화 45/35/20%, 하강 30/40/30%입니다. 위험 점수 40 이상이면 주식에서 현금으로 10%p, 70 이상이면 20%p를 이동하는 가설입니다. 개인의 자금 필요, 환율, 세금, 채권 위험, 보유종목 위험은 자동 반영되지 않습니다.

시장 위험도 시뮬레이터에서 VIX·하이일드·200일선 괴리·CLI 국면을 변경하여 가정 계산을 할 수 있습니다. 최신 모델값 불러오기와 금융위기 가정 버튼은 시나리오 입력 편의 기능이며 실데이터 또는 저장 포트폴리오를 수정하지 않습니다.

### 분야별 시장 진단 (실험)

대시보드에서 미국 경기·고용, 물가·금리, 유동성, 신용, 주식 추세, 한국 경기·시장, 반도체·전자부품의 규칙별 관측값을 확인합니다. 자료가 하나라도 부족하면 해당 분야는 판단 보류입니다. 경계 조건 개수는 확률이나 종합 점수가 아니며 기존 배분에 반영하지 않습니다. 제공처별 신선/오래됨/누락 및 오류 상태를 확인한 뒤 관리자 연결 검사로 원인을 확인하세요. 실제 API 응답 검증과 규칙의 과거 성과 검증은 별도입니다.

### 5개 파생 참고치

- 미국 순유동성: (연준 자산 - TGA) / 1,000 - ON RRP. 원자료를 십억 달러로 통일하고 동일 수요일 값을 사용합니다. 실제 위험자산 유입액이 아닙니다.
- SOFR-IORB: 동일 관측일 담보부 조달금리에서 준비금 이자율 차감. 단기 자금시장 압력 참고.
- 미국 기타 전자부품 재고/월간 출하: 동일 월 재고액과 월간 출하액 비율. 메모리 전용 재고 일수가 아님.
- 미국 세후 조정 기업이익/GDP: 동일 분기의 계절조정 연율 금액 비교. 개별 기업 영업이익률이 아님.
- 미국 비금융기업 주식 부채/GDP: 주식 부채 평가액을 GDP와 비교한 참고 비율. 전체 증시 시가총액/GDP 또는 PER이 아님.

날짜 불일치, 오래된 자료, 수집 오류, 분모 0 등은 계산 보류합니다. 신규 파생 지표는 기존 위험 점수에 합산하지 않습니다. 검증된 다분야 위험도 모델이나 자동 매매 신호는 아직 제공하지 않습니다.

## 07. 국내 증시·수급과 관심종목

접속 메뉴: 국내 증시 · 수급 (/kr-market). KIS 실전 키 등록 후 시장 수급 수집을 누릅니다.

- 코스피/코스닥 선택 후 외국인·기관·개인 순매수액, 일별/구간 누적 그래프, 5·20·60개 유효 관측일 누적 및 외국인 연속 매수/매도를 확인합니다. 단위는 억원이며 실제 HTS와 대조하세요.
- 관심종목: 관리자 인증 후 6자리 종목코드와 표시 이름을 입력하고 등록/편집 저장을 누릅니다. DART 고유번호는 선택입니다. 최대 20개 종목을 서버에 저장합니다.
- 종목별 갱신과 상세 보기에서 종가·수급을 확인합니다. 관심종목 삭제는 목록 제외이며 저장 이력까지 지우지 않습니다.
- 기업 실적: OpenDART 키 등록 후 종목코드, 사업연도, 보고서(사업/분기/반기), 연결/별도를 선택해 공시 조회를 누릅니다. 고유번호는 공란이면 자동 검색합니다.
- 분기/반기 해당 기간 금액과 연간 실적, 누적 실적, TTM 및 예상 EPS를 구분합니다. 계정이 불명확하거나 이전 이익이 양수가 아니면 일부 성장률을 보류합니다.

오늘을 제외한 저장 관측값을 사용하며 실시간 주가가 아닙니다. 5/20/60은 실제 거래일 달력을 보장한 기간이 아니라 저장된 유효 관측일 수입니다. 원주가는 배당·분할의 영향을 받을 수 있습니다.

## 08. 수급 순위·업종 분석

접속 메뉴: 수급 순위 · 업종 (/kr-insights). KIS 키와 관리자 인증이 필요합니다.

- 시장, 투자자(외국인/기관), 순매수·순매도 방향을 선택하여 가집계 조회를 누릅니다. 공급처 반환 종목 중 최대 30개를 정렬합니다.
- 장중 가집계는 확정 수급이 아닌 증권사 추정치입니다. 프로그램은 평일 10:00~15:30 KST에 수동 조회를 허용하지만 실제 휴장일·특별 거래시간을 자동 판별하지 않습니다.
- 관심종목 수급 비교에서 공통 관측일 수(1·5·20·60), 정렬 기준, 방향을 선택하고 동일 기간 비교를 실행합니다.
- 외국인·기관 동반 순매수 필터를 사용해 후보 종목을 좁힐 수 있습니다. 누락 종목은 제외 내역에서 확인하고 0으로 채우지 않습니다.
- 업종 태그를 직접 지정하면 관심종목 표본 기반 히트맵이 표시됩니다. 공식 전체 업종 수급은 아니며 태그는 브라우저별로 저장됩니다.

같은 기간·같은 단위의 자료끼리 비교하며, 수급 순위만으로 이후 상승 또는 매수 주체의 목적을 단정하지 않습니다.

## 09. 시장 압력: 프로그램·선물·공매도·대차

접속 메뉴: 시장 압력 관측소 (/kr-pressure). 시장 및 관심종목, 요약 관측일 수를 선택합니다.

- 저장 자료 조회: 기존 자료로 차트와 요약을 표시합니다.
- KIS 수동 수집: 프로그램 차익/비차익 순매매 수량, 선택 종목 공매도 거래량/비중, 대차 신규·상환·잔고를 갱신합니다. 기존 자동 거시 수집에 포함되지 않습니다.
- 공매도 거래량은 해당 기간 체결량이고, 공매도 순보유잔고는 남아 있는 포지션입니다. 대차잔고 전체가 공매도라는 뜻은 아닙니다. 잔고 자체를 기간 합산하지 않습니다.
- 현물/선물 비교: 동일 최신 관측일의 방향을 비교합니다. 현물 억원과 선물 계약 수를 합산하지 않습니다.

### 공식 원자료 수동 CSV 등록

[KRX Data Marketplace](https://data.krx.co.kr/contents/MDC/MAIN/main/index.cmd)에서 자료를 확인한 후 빈 템플릿 저장을 눌러 프로그램 표준 형식으로 변환합니다. KRX 원본 CSV를 그대로 자동 인식하는 기능은 아닙니다.

```csv
date,foreign_contracts,institution_contracts,individual_contracts
2026-10-01,100,-70,-30
```

위 예시는 코스피200 선물 순매수 계약 수 형식의 가상 값입니다. 공매도 순보유잔고 템플릿은 아래와 같습니다.

```csv
date,balance_qty,balance_pct
2026-10-01,10000,0.12
```

선택 종목과 원자료 기준, 완료 관측일, 단위를 확인하고 확인 체크 후 CSV 등록합니다. 최대 400행·200KB이며 날짜 중복은 허용하지 않습니다. 기존 동일 날짜는 확인 후 교체됩니다. 사용자 등록 자료는 프로그램이 공식 원문과 대조한 값이 아닙니다.

## 10. 기업 가치·배당 분석

접속 메뉴: 기업 가치 · 배당 (/kr-value). 국내 증시 메뉴에서 보통주 관심종목을 등록하고 OpenDART 키를 설정합니다.

1. 관심종목, 연결/별도 재무제표, 최근 5년/10년을 선택합니다.
2. OpenDART 공시 수집을 실행합니다. 이미 수집한 자료는 저장 자료 조회로 확인합니다. 정정 공시 반영 시 오늘 성공한 자료도 다시 조회를 체크합니다.
3. 매출·영업이익·순이익·기본 EPS·마진·성장률·영업현금흐름·ROE·FCF 등 사용 가능한 연간 자료와 원문을 검토합니다.
4. 보통주 배당 이력과 최근 배당 공시를 확인합니다. 연간 DPS를 분기 배당과 중복 합산하지 않습니다.
5. 배당 기준일·배당락일·지급일·회차별 DPS는 실제 공시와 거래소에서 확인해 수동 등록합니다. 공시 접수일이나 결산일을 배당 기준일로 간주하지 않습니다.

### 과거 밸류에이션 비교

```csv
date,price,eps,bps
2026-10-01,50000,5000,40000
```

가상 예시입니다. 해당 시점에 공개된 동일 기준 EPS/BPS와 종가를 준비하고 출처·기준을 입력합니다. 등록은 기존 해당 종목 비교 자료를 교체합니다. 미래에 발표한 실적을 과거 날짜에 넣으면 미래정보 편향이 생깁니다. 최대 400행이며 적자 EPS에는 PER 계산을 보류합니다.

### 적정가·배당 재투자 가정

최신 유효 종가·최근 연간 EPS·DPS 적용을 누르거나 직접 입력한 뒤 PER/PBR 보수·기준·낙관 배수를 설정합니다. 적정가 참고값은 EPS×PER, BPS×PBR이며 가정 ROIC 등도 입력한 값으로 계산합니다. 과거 EPS를 미래 예상 EPS로 오인하지 마세요.

배당 재투자는 초기 투자금, 연간 배당수익률, 배당 제외 주가수익률, 배당세율, 기간을 가정한 비교입니다. 가격·배당 변화율이 일정하다는 가정이며 실제 배당금이나 향후 수익률을 보장하지 않습니다. DART 공시·배당 수집은 수동 기능입니다.

## 11. 일간·주간 AI 보고서 — API 없이 사용

접속 메뉴: 투자 분석센터 (/intelligence). AI API 설정이 없어도 핵심 기능을 이용할 수 있습니다.

1. 분석 기간을 일간 관측 또는 주간 관측으로 선택합니다.
2. 분석 범위를 전체 시장 또는 등록된 관심종목으로 선택합니다.
3. 현재 자료 조회를 누르고 기준일, 신선한 지표 수, 누락된 자료를 확인합니다.
4. 규칙 리포트 저장을 눌러 당시 관측자료를 저장할 수 있습니다.
5. AI API 없이 분석하기를 열고 프롬프트 + 데이터 복사 버튼을 누릅니다. 복사가 차단되면 입력란을 직접 복사하거나 프롬프트 TXT 다운로드를 이용합니다.
6. [ChatGPT](https://chatgpt.com/), [Gemini](https://gemini.google.com/), [Claude](https://claude.ai/) 채팅에 복사한 전체 내용 또는 TXT 파일을 넣어 보고서를 요청합니다.

프롬프트에는 기준일, 지표 ID, 실제 저장 관측값, 관측일, 단위, 원자료 출처, 기간별 변화, 장기 백분위(가능한 경우), 비교 스냅샷, 위험 모델, 데이터 품질이 포함됩니다. 선택 종목 코드도 포함될 수 있습니다. API 키, 개인 보유수량·매입단가, 사용자 수동 일정·CSV는 제외합니다. 외부 AI 서비스의 데이터 정책과 원자료 이용조건을 확인하세요.

AI가 최신 시세·뉴스·예상치 등을 임의로 만들지 않도록 지시하지만, 해석의 정확성을 보장하지 않습니다. AI가 제시한 수치와 결론을 관측 근거에서 확인하세요. 이 방식은 프로그램의 AI API 호출 비용이 없으며 채팅 서비스의 요금/사용량 제한은 별도입니다.

### 매일 자동 저장하는 방법

관리자 설정 → 수집 일정 및 실행에서 자동 수집을 켜고 KST 시각을 저장합니다. AI 투자 분석 API 설정에서 예약 수집 후 무료 리포트 저장을 자동 저장으로 지정합니다. 기본값은 ON이지만 자동 수집 자체는 기본 OFF입니다.

성공 또는 일부 성공한 예약 수집 뒤 전체 시장 일간 규칙 리포트가 저장됩니다. 저장 리포트 이력에서 날짜를 선택하면 작성 당시 자료로 프롬프트를 다시 복사할 수 있습니다. 수동 수집 후에는 규칙 리포트 저장을 직접 실행하세요. 서버가 꺼져 있는 동안의 보고서 소급 생성이나 이메일·메신저 전송 기능은 없습니다.

## 12. AI API 직접 연동과 보고서 이력

### 관리자에서 설정하기

- AI 투자 분석 API에서 OpenAI, Gemini, Claude 중 하나를 선택합니다.
- 해당 제공처 API 키와 실제 계정에서 지원하는 모델 ID를 입력합니다. [OpenAI 키](https://platform.openai.com/api-keys), [Gemini 키](https://aistudio.google.com/apikey), [Claude 키](https://console.anthropic.com/settings/keys).
- KST 일일 유료 호출 제한(1~20, 기본 3)과 최대 출력 토큰(256~3000, 기본 1200)을 지정한 후 AI 설정 저장을 누릅니다.
- 기본값은 AI_PROVIDER=off입니다. 일반 ChatGPT 구독과 API 이용 요금은 별개일 수 있습니다. 키 등록 표시가 연결 성공을 뜻하지 않습니다.

### 수동 및 자동 생성

투자 분석센터에서 현재 자료 조회 → AI 추가 해석 및 외부 전송 동의 체크 → AI 해석 생성 · 저장 순으로 진행합니다. API 요청은 실제 비용이 발생할 수 있습니다. 응답은 근거 ID와 형식 검사를 거친 짧은 보조 해석이며 외부 채팅 프롬프트로 요청한 긴 보고서와 분량이 다를 수 있습니다.

예약 수집 후 유료 AI 해석을 명시적으로 ON으로 설정하면 예약 수집 뒤 무료 리포트를 먼저 보존하고, 해당 KST 날짜에 유료 시도 이력이 없을 때 최대 한 번 호출합니다. 기본 OFF입니다. 실패한 시도도 제한에 포함되며 자동 재시도하지 않습니다. 동일한 자료의 정상 저장 리포트는 재사용할 수 있습니다. 일일 횟수 및 출력 토큰 제한은 실제 요금 상한을 보장하지 않습니다.

저장 리포트 이력의 기간·종목·제공처·상태·사용량을 확인하고 저장된 리포트를 열거나 TXT로 다운로드합니다. 당시 관측 근거를 사용하므로 현재 데이터로 몰래 바뀌지 않습니다. 과거 AI 해석을 자동 수익률 예측 또는 정확도 검증 결과로 해석하지 마세요.

## 13. 경제지표 발표 캘린더

접속 메뉴: 투자 분석센터 → 경제지표 발표 캘린더 (/intelligence#calendarPanel).

- BLS 일정 갱신: 미국 노동통계국의 공식 일정 피드를 조회합니다. 관리자에서 BLS 일정 자동 갱신을 선택하면 예약 수집에 연동됩니다.
- 표시 기간과 기관 필터, 지난 일정 표시 범위를 선택합니다. 미국 동부/영국 런던 등 현지 시간대와 한국시간 변환 결과를 확인합니다.
- BEA(PCE/GDP), FED(FOMC), BOK, KOSIS, OECD 등은 공식 일정을 확인해 직접 등록할 수 있습니다. 모든 기관의 발표 일정을 자동 수집하는 것은 아닙니다.
- 지표명, 발표일·현지 시각·시간대, 기관, 공식 일정 URL, 상태를 선택합니다. 발표된 결과는 동일 단위의 이전값·실제값·사용자가 확인한 예상값 및 공식 결과 URL을 등록할 수 있습니다.
- 예정·발표·취소 상태를 관리하고 수정/삭제합니다. 예상값이 없으면 공란으로 유지하고, 실제값과 예상값의 차이는 동일 단위의 수치로만 해석합니다.

일정 변경 가능성이 있고, 자동 피드 수집 오류 시 이전 자료가 보존됩니다. 사용자가 직접 등록한 값은 프로그램이 원문과 자동 대조한 값이 아닙니다.

## 14. 포트폴리오 및 스트레스 테스트

접속 메뉴: 대시보드 → 포트폴리오 (/#portfolio).

- 개별 종목 적정가 계산: 종목명, 통화, 예상 EPS, 현재가, 보수·기준·낙관 PER, 주식 수를 입력합니다. EPS×PER의 가정별 참고가를 계산하고 보유종목 저장을 누릅니다.
- 내 보유종목: 편집, 삭제가 가능하며 기본 저장 위치는 브라우저 localStorage입니다. 통화별 평가액을 표시하며 자동 환율 환산/실시간 계좌 연동이 아닙니다.
- 서버에 저장: 관리자 인증 후 현재 보유종목·배분·스트레스 입력값의 저장본을 DB에 기록합니다. 서버에서 불러오기는 확인 후 현재 브라우저 값을 덮어씁니다. 여러 사용자 계정/여러 저장 버전은 지원하지 않습니다.
- 자산배분·리밸런싱: 주식/ETF, 채권, 현금 보유액을 만원 단위로 입력합니다. 경기 모델 또는 직접 목표 비중을 선택해 목표와 현재의 차이를 확인합니다. 합계 100% 확인.
- 급락 스트레스 테스트: 주식 중 반도체·AI 비중과 해당 업종/기타 주식/채권의 가정 수익률을 설정합니다. 현금 수익률 0% 가정의 포트폴리오 평가액 변화를 계산합니다. 레버리지 ETF 경로, 세금, 환율, 거래비용은 반영하지 않습니다.

개인 투자금과 보유종목은 AI 프롬프트에 자동 포함되지 않습니다. 서버 DB 포트폴리오는 별도 암호화되지 않으므로 호스트와 DB 접근 권한을 보호하세요.

## 15. 자산배분 백테스트 (실험)

접속 메뉴: 대시보드 → 백테스트 (/#backtestPanel). 동일 통화의 월말 주식·채권·현금 총수익 지수(배당/이자 재투자)를 연속된 완료 월로 준비합니다.

```csv
month,stock,bond,cash
2025-01,100,100,100
2025-02,102,100.4,100.3
2025-03,101.5,101.2,100.6
```

가상 형식 예시이며 실행에는 최소 13개의 연속 월 관측값이 필요합니다. 숫자는 양수, 천단위 쉼표 없이 입력합니다.

1. CSV 파일 선택.
2. 발표 지연 가정(2~12개월)과 편도 매매비용(0~100bp) 입력.
3. 백테스트 실행 후 전략/주식 100% 비교 누적수익률, 연복리(CAGR), 월말 최대낙폭(MDD)을 확인.

미국 CLI의 기본 4국면 배분만 시험합니다. VIX·하이일드·200일선 위험 조정은 제외하며 최신 개정 CLI를 사용하므로 최초 발표 시점의 진정한 백테스트가 아닙니다. 세금·환율·슬리피지는 반영하지 않습니다. CLI 자료 누락 또는 보합으로 실패하면 이력과 기간을 확인합니다.

## 16. 자주 발생하는 문제와 해결

### 연결 검사 실패 / 401 / 403

관리자 인증 사용자명 admin과 비밀번호를 확인합니다. 공급처 키를 수정했으면 반드시 설정 저장 후 연결 검사를 실행합니다. 실데이터 모드인지, API 사용 승인·키 유효기간·접속 IP·호출 제한이 정상인지 확인합니다. 설정을 여러 브라우저에서 동시에 바꾸지 마세요.

### KOSIS 조회 실패

기본 순환변동치 설정, 전국 월간 단일 항목, API 활용 신청과 원문 키를 확인합니다. 통계표 오류를 해결하려고 기존 데이터를 먼저 삭제하지 마세요. 초기화가 필요하면 해당 지표 CSV 및 DB 백업 후 원자료 확인을 거쳐 진행합니다.

### OpenDART 조회 실패

관리자 국내 증시·기업 실적 API에서 OpenDART 연결 검사를 실행합니다. 기업개황, 고유번호 목록 ZIP, 표본 연결 재무제표·배당 단계별 결과를 봅니다. 인증·IP 제한·호출 제한·미공시 사업연도 또는 연결/별도 자료 유무를 구분합니다. 필요한 경우 DART 원문과 고유번호를 직접 대조합니다.

### 관세청 또는 신규 지표 미수집

관세청 서비스 활용 승인, 서비스 키, 공식 품목별 API 응답을 확인합니다. HS 8542에 HS 854232를 더하지 않습니다. 월간 이력이 빠졌거나 하위 품목만 반환되면 저장하지 않고 이전 자료를 보존합니다. 원자료 시리즈가 중단되거나 제공범위가 바뀌면 해당 지표가 오래됨/실패로 표시될 수 있습니다. 신규 시리즈 및 실제 API 단위는 사용자 환경에서 공식 표와 대조해야 합니다.

### AI 해석 실패 / 프롬프트 복사 안 됨

선택 제공처, API 키, 모델 ID, 요금/한도 및 전송 동의를 확인합니다. 실패한 유료 호출을 반복하지 말고 규칙 리포트 또는 프롬프트 TXT를 사용합니다. 복사 권한이 없는 모바일/HTTP 브라우저에서는 입력란을 직접 선택하거나 TXT 다운로드로 대체합니다. 수집 진행 중이거나 유효 근거가 없으면 프롬프트가 비활성화될 수 있습니다.

### 위험도·파생값이 보류 / 자동 보고서가 없음

필수 지표 최신 상태, S&P 500 200개 이상 유효 관측 이력, CLI 3개월 전 자료, 파생값의 동일 관측일을 확인합니다. 자동 보고서가 없으면 자동 수집과 무료 자동 저장이 켜져 있는지, 예약 수집이 성공/일부 성공했는지, 서버가 실제로 실행 중인지 확인합니다. 같은 날 실패 후 자동 재시도가 보장되지 않으므로 필요한 경우 수동 수집·저장을 실행하세요.

## 17. 보안·백업·업데이트 및 미구현 범위

- 개인용 단일 사용자·단일 서버 프로세스 앱입니다. 로컬 주소에 한정하고 외부 호스팅 시 HTTPS, 전 페이지 인증, 충분히 긴 무작위 비밀번호(HOSTED_MODE는 24자 이상)를 사용합니다. 공개 인터넷에 인증 없이 노출하지 마세요.
- SQLite/DB, Docker 볼륨, 암호화 설정 파일 settings.enc와 복호화 키 settings.key를 안전한 위치에 함께 백업합니다. 암호화 키를 잃으면 저장 인증정보를 복구할 수 없습니다. 로컬 DB를 임의 삭제하지 마세요.
- 업데이트는 기존 Compose 프로젝트 이름과 DB/볼륨, 설정 경로를 유지하고 백업 후 진행합니다. 저장된 .env를 덮어쓰지 않고, 이미지 재빌드 후 관리자 연결 및 상태를 확인합니다.
- API 문서 (/docs)는 개발용 엔드포인트 설명입니다. 일반 사용자는 이 매뉴얼과 지표 학습센터를 이용하면 됩니다.
- 현재 미구현: 관세청 10·20일 잠정치, DRAM/NAND 개별 현물·계약가격, PMI/시장 컨센서스·금리선물 자동 수집, 전체 시장 PER/CAPE·예상 EPS 자동 연동, 검증된 분야별 위험도 모델, 시점별 검증 백테스트, 자동 매매·주문, 푸시/이메일 알림.
- 자동화 테스트는 모의 API 응답과 격리된 DB를 검증하는 것이며 실제 키 승인·운영 서버 수집률·제공처 사용권·실제 투자 성과를 보장하지 않습니다. 공식 원자료를 항상 대조하세요.

문서와 앱의 내용은 같은 Markdown 원본(app/USER_MANUAL.md)을 사용합니다. 프로그램을 변경하면 해당 절차와 제한 사항도 이 문서에서 함께 갱신합니다.
