2. 알림 종류 및 시간

자동 알림은 명시적으로 활성화할 때만 전송됩니다.

종목코드, above(이상) 또는 below(이하), 원화 가격. 관심종목에 먼저 등록하세요. 이전 일별 종가와 최신 종가 사이에 실제 조건을 넘은 경우만 해당하며 장중 실시간 가격은 아닙니다. 조건을 처음 등록하면 최근 관측일에 이미 발생한 도달이 알림에 포함될 수 있습니다.

활성화 시 Telegram 외부 서비스로 공개 시장 관측값, 종목코드·선택한 가격 기준, 등록된 일정의 날짜가 전송됩니다. 개인 보유 수량·매입단가·포트폴리오·비밀번호 및 다른 API 키는 보내지 않습니다. 데모에서는 외부 전송하지 않습니다.

3. 모바일 앱 설치

기존 웹 서비스의 홈 화면 설치 방식입니다. 별도 앱스토어 배포는 아닙니다.

Macro Invest

HTTPS 또는 localhost에서 설치할 수 있습니다. 로그인 정보나 투자 데이터를 오프라인 캐시에 보관하지 않습니다.

Android: 브라우저 메뉴 → 앱 설치 또는 홈 화면에 추가. iOS: Safari 공유 → 홈 화면에 추가. 독립 앱은 인터넷 연결과 기존 인증이 필요합니다.

4. 전송 이력

최근 100개 시도 · 자동 최대 20회/일 · 테스트 60초 간격 · 중복 재전송 차단

시각 KST종류상태설명

서버 실행 중 매분 확인. 연결 실패나 중단 시 수신 여부가 불확실할 수 있어 자동 재전송하지 않습니다. 실패 시 해당 확인 주기의 나머지 전송을 멈추고 15분 동안 자동 전송을 보류합니다. 자동 한도 초과·서버 중단 시 일정 알림을 놓칠 수 있습니다.
