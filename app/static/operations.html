데이터베이스 백업

운영 DB의 일관된 스냅샷 · SHA-256 검증

백업에는 투자 기록 등 민감한 자료가 포함됩니다. API 키·설정 암호화 키·관리자 비밀번호는 포함하지 않습니다. DB 파일과 메타데이터를 별도 안전한 저장소에 함께 보관하세요.

자동 백업은 서버 실행 중 설정 시각 이후 하루 1회. 성공한 자동 백업만 순환 삭제하며 수동 및 복원 직전 백업은 자동 삭제하지 않습니다. 다른 검증된 백업이 있을 때만 수동 삭제할 수 있습니다. DB당 128 MiB 제한, 시작 전 256 MiB 여유 필요. 데모 자동 백업은 실행되지 않습니다.

복원 안내

전체 DB 복원은 안전을 위해 웹에서 실행하지 않습니다. 운영 서버와 모든 수집 작업을 중지하고 같은 버전·DB 종류·모드에서 검증된 백업을 복원하세요. 기존 DB를 먼저 별도 백업하며 알림·자동 수집·자동 백업을 중단합니다.

로컬: python -m app.ops_restore BACKUP_ID --confirm RESTORE

Docker: docker compose stop app 후 docker compose run --rm app python -m app.ops_restore BACKUP_ID --confirm RESTORE를 실행합니다. 이후 복원 결과 확인 후 서버를 시작합니다. 설정 복구와 Render 복원은 배포 문서를 참고하세요.

복원 직후 외부 알림은 다시 활성화하기 전에 과거 발송 이력과 현재 이벤트를 확인하세요. 장부만 가져오려면 투자 일지의 JSON 가져오기를 사용하세요.

개인용 단일 서버 운영 · 백업 다운로드 파일은 외부 공유 금지 · 정기 복원 테스트 권장
