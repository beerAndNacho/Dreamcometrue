기업 가치평가 · 배당 재투자

공시 실적과 직접 입력한 가정을 구분합니다. 자동 매매 신호가 아닙니다.

직접 입력 모드. EPS를 예상치로 입력할 경우 결과는 예상 PER입니다.

ROIC는 영업이익 × (1 − 가정세율) / 직접 입력 평균 투하자본. PBR은 입력 BPS 기준. 적자 EPS에는 PER·EPS 기반 적정가를 표시하지 않습니다. 자본 구조와 보통주/우선주 권리 차이를 확인하세요.
